💡 How does this work?

The model analyzes functional connectivity between brain regions using three atlases (Harvard-Oxford, AAL, Destrieux). The regions shown above have the strongest influence on predicting the emotion. Higher importance scores indicate regions with stronger connectivity patterns characteristic of this emotional state.

🧬 BOLD Signal: Blood-Oxygen-Level-Dependent signal measures brain activity. Higher BOLD values indicate more active regions. The activation level badges (High/Medium/Low) show how active each region is, helping confirm that the predicted emotion matches the brain's activity patterns.
